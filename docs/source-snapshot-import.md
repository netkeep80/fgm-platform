# S02B — импорт закреплённых снимков

`docs/source-snapshots.json` задаёт источники и точные HEAD/TREE. Каталоги `core/`, `regenerator/` и `renderer/` содержат все 305 исходных файлов с сохранёнными Git-байтами, именами и режимами. Единственный родитель импортирующего коммита — закреплённый Platform BASE. Исторические Git-коммиты доступны в исходных репозиториях.

`scripts/check-source-snapshots.py` проверяет три Git-поддерева, количества файлов, сохранность всех прежних файлов Platform, набор допустимых добавлений и соответствие коллекции ресурсов. Равенство TREE удостоверяет все вложенные имена, blob SHA и режимы. CI выполняет эти проверки и шесть отрицательных/положительных регрессионных сценариев на Ubuntu и Windows.

```sh
python -m unittest discover -s tests -p test_source_snapshots.py -v
python scripts/check-source-snapshots.py --head HEAD --base 9a1b41b7050ee2342d247f8d43ce5e3977de2ee6
```

Новый кандидат `FGMP-MIG-SNAPSHOT-001` обосновывает snapshot через существующую явную коллекцию `repo-guard/resource-collection/v0`. В `docs/source-snapshot-resources.json` перечислены только 305 файлов импорта. Корневые нормативные Requirements Platform сохраняют прежние байты. Исходные Requirements внутри трёх каталогов сохраняются как артефакты снимка; перенос их нормативных связей в корневую систему относится к S03.

Следующие этапы адаптируют пути сборок, Native/WASM, Studio и Pages. Источники, старые Issues, PR и аудиты доступны через принятые реестры Platform. UFO Fractal остаётся внешним потребителем. Снимки прошли проверку имён и содержимого на игровые ассеты, приватные ключи и известные форматы токенов; найденных совпадений нет.
