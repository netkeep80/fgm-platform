# Поверхность результата native R07 в Reconstruction Studio

Этот срез связывает **точный результат существующего native R07** с непрерывной
поверхностью и четырьмя новыми глобальными камерами Studio. Ранее four-view путь
показывал только voxel-boundary OBJ исходного BuildWholeObject. Исходный режим
сохраняется, пока дополнительный файл R07 не выбран.

**StageA NOT_ACCEPTED / PRIVATE_ACCEPTANCE_PENDING.** Принадлежность B1 остаётся
условной гипотезой; успешные SHA/C05/синтетические тесты не удостоверяют настоящий
ObjectDefinition. Нужны независимый локальный source/binary replay, проверка состава,
соседей/швов конкретного объекта и отдельная авторская семантическая/визуальная приёмка.

## Локальный путь

1. Выполнить существующий [source-bound R07 fit](r07-whole-source-fit.md) с теми же
   SHA-pinned native binaries и preflight; параметры команд не изменены. Публичная
   проверка использует только синтетические данные.
2. Новый выходной каталог атомарно содержит прежние `whole-baseline.fgm.json`,
   `whole-candidate.fgm.json`, `joint-fit-receipt.json`, а также `fit-preview.json` и
   точные подготовленные `receipt.json`, `loft-0.json` … `loft-N.json` этого запуска.
   Для синтетического joint-fit экспортируется `fit-preview.json`; подготовленные
   B1/R03 файлы берутся из того же синтетического примера. Новые имена каталогов
   обязательны; существующие результаты не заменяются.
3. Записать SHA-256 **байтов файлов**, включая финальную новую строку, если она есть.
   Например, PowerShell: `Get-FileHash -Algorithm SHA256 fit-preview.json`;
   Ubuntu: `sha256sum fit-preview.json`. SHA пакета внутри envelope относится к
   канонической строке без новой строки, SHA импортируемого файла — ко всем байтам.
4. В Studio в режиме целого объекта выбрать `receipt.json` и `loft-*.json`, внести
   независимо записанные SHA в существующее поле. Отдельно выбрать `fit-preview.json`
   в поле результата native R07 и внести его SHA. Нажать «Собрать объект».
5. Studio заново строит baseline из B1/R03, проверяет его связь с моделью R07 и
   повторяет **в WASM** все C05 и метрики исходных силуэтов. Затем показывает четыре
   глобальных вида нового OBJ, исходные силуэты/до/после и численные метрики. FGM,
   OBJ, отчёт, срезы, provenance и receipt видов можно сохранить локально.

Оригинальные игровые ресурсы, силуэты и производные модели остаются локальными.
Не загружать этот каталог в публичный GitHub, Pages или CI. Никаких автоматических
сетевых запросов с этими данными нет.

## Контракт и границы

`fgmr-r07-fit-preview-input/1` содержит baseline/membership/winner SHA, канонический
winner package, observation cells и исходный fit receipt. Import проверяет точные
SHA, известную derivation и полный граф. Поддержаны исходный R06 пакет и действующие
общие R07 isotropic extent, axis extent и axis translation. Сохранены существующие
диапазоны кандидатов; произвольные FGM программы отвергаются. Новый evaluator или
LOFT decoder не вводится: Core выполняет C05, существующий C++ R07 observer выполняет
построение силуэтов в native и WASM. Данные наблюдений проверяются по локальным SHA,
но не получают независимой source-аттестации от самого импорта.

Экстрактор вычитает перекрывающие прямоугольники из граней текущего объединения
коробок, удаляет внутренние грани и назначает одного владельца совпадающей грани.
Границы поддержанной грамматики лежат на точной millivoxel сетке; нормализация
координат устраняет ложные щели от разных путей float-арифметики. Это точная
непрерывная поверхность этой **ограниченной** модели, а не извлечение произвольного
FGM и не доказательство истинной формы скрытых поверхностей. Допускаются T-junctions
между копланарными треугольниками; общий indexed watertight mesh не обещается.

Ограничения импорта: до 8 клеток, 128 коробок, файл R07 до 256 KiB, все входы до
512 KiB, до 2 млн операций отсечения, 8192 фрагмента одной грани, 65536 вершин и
768 KiB OBJ; общий выход существующего Studio ABI — до 1 MiB. Отказ не выдаёт
частичных артефактов. При недоступном WebGPU канонические результаты сохраняются,
но четыре вида не подтверждаются.

Метрики: micro/per-observation silhouette intersection/union и количества pixels.
Существующий R07 cell-ray observer остаётся приближённым с шагом 0.125 voxel,
**UNRESOLVED_THIN_FEATURES_AND_CROSS_CELL_OCCLUSION**. Контурная tie-break метрика
сохраняется в исходном fit receipt; импорт повторно проверяет IoU и запрет регресса,
не весь поиск и не оптимальность winner. Четыре глобальные камеры используют
реальную общую геометрию и существующий WebGPU depth, независимо от этих клеточных
силуэтов. RendererSession сохраняет существующий auto-fit каждой камеры; утверждение
об общей физической калибровке/общем zoom всех проекций не делается.

`OBSERVED`: импортированные occupancy/силуэты; `INFERRED`: непрерывная геометрия R07;
`UNKNOWN`: истинные скрытые детали; `UNRESOLVED`: независимая принадлежность частей.
Изменение входов и отмена удаляют старые виды/экспорты. Атомарный C++/WASM вызов
прерывается завершением Worker; это **не итеративный browser R07**, без progress,
pause/resume/checkpoint. Полный browser fit и Stage B требуют следующих срезов.

## Воспроизводимая синтетическая демонстрация

Из корня после обычной native сборки:

```sh
python regenerator/tests/test_r07_fitted_surface.py \
  build/native/regenerator/fgmr-studio-native \
  build/native/regenerator/fgmr-r07-whole-surface --fixtures /tmp/r07-demo
```

В Windows добавить `.exe` и выбрать новый доступный каталог вместо `/tmp/r07-demo`.
Выбрать полученные файлы в Studio по инструкции выше. Fixture — асимметричное
кольцо со сквозным отверстием, вертикальным перекрытием и переходом через клеточный
шов, без оригинальных ресурсов. Target задан аналитическими коробками; настоящий
native joint-fit выбирает дробное расширение +0.49 при неизменной занятости.

`test_r07_fitted_surface.py` независимо сверяет границы, площадь/объём объединения,
внешнее направление граней, отверстие и отсутствие внутренней поверхности;
Core дополнительно проверяет центры соседей. Тест отвергает подстановку прежнего
voxel OBJ к новой модели, неверные SHA/принадлежность/строки/метрики/деформации.
`r07-fitted-surface.browser.mjs` исполняет тот же native fit → настоящий WASM
Worker → четыре WebGPU кадра, сверяет их silhouette с аналитическим CPU ray/box
oracle, реальные скачанные package/mesh hashes, неверные камеры/заполненное
отверстие/прежнюю геометрию и устаревший GPU readback после отмены. У oracle
явно исключается полоса 0.025 voxel у границ; сравниваются каждый третий пиксель
и foreground/background, а не непрерывная cross-device RGBA идентичность.
Существующий отдельный depth oracle и four-view RGB/inverted-depth тесты сохраняются.

Native CTest включает этот тест на Ubuntu/Windows; существующий единственный CI
дополнительно обязательно исполняет browser тест и сохраняет screenshot. RepoGuard
связывает реализацию/исполнение с `FGMR-R07-FITTED-SURFACE-001`; lifecycle остаётся
кандидатным до отдельного решения автора.
