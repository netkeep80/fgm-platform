# STUDIO-S2B — сравнение одной клетки

Сборка для проверки запускает локальный R06 через реальный WASM Worker из снимка регенератора (историческая запись). Формат `fgmr-studio-r05-observation/1` описан в [контракте STUDIO-S2B0](https://github.com/netkeep80/fgm-platform/blob/main/regenerator/docs/studio-s2b0-r05-observations.md). Координаты приходят из нативного R05, а холст отображает их в общей системе отсчёта с целочисленным масштабом.

| Режим | Что показывает |
| --- | --- |
| Оригинал | Полный индексированный кадр 32×40 с выбранной палитрой R04. |
| Реконструкция | Силуэт FGM-занятости, сверенной с LOFT на 6144 центрах. |
| Наложение | Зелёные совпадения, голубые пиксели только реконструкции, янтарные пиксели только исходного наблюдения. |
| Разница | Только голубые и янтарные расхождения. |
| Коллизии | Пурпурная проекция проверенной LOFT-занятости на R05. |
| Свободный вид OBJ | Диагностический вид экспортированной сетки с вращением и масштабом. |

Если R05 использовал правую половину кадра, это указано в режимах сравнения. Оригинал по-прежнему показывает полный кадр. Коллизии показаны проекцией занятых вокселей, поэтому силуэт совпадает с режимом реконструкции. Для пространственного осмотра доступна сетка OBJ.

До отображения проверяются SHA-256 строки `visual`, версия и размер схемы, координаты, принадлежность клетке, размеры спрайта, палитра и равенство счётчиков с отчётом. При отсутствующем или повреждённом наблюдении холст и кнопки экспорта очищаются. Смена ресурсов и параметров инвалидирует предыдущий результат. Хеш связывает наблюдение с данным пакетом результата. Локальные исходные файлы и полученные пиксели не отправляются в сеть.

## Локальная проверка

Команды выполняются из корня Platform после активации Emscripten 4.0.21. Все движки собираются из одного текущего checkout; engine-lock задаёт runtime contract, а Platform SHA/TREE вычисляются producer из этой сборки.

```sh
npm ci --ignore-scripts --no-audit --no-fund
emcmake cmake -S . -B build/wasm -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF
cmake --build build/wasm --parallel 2
npm run build --workspace renderer
node renderer/scripts/build-studio-s2a.mjs build/wasm
npx playwright install chromium
(cd renderer && node --test tests/studio-r05.test.mjs tests/studio-ufo-catalog.test.mjs)
(cd renderer && node tests/studio-s2a.browser.mjs build/studio --catalog)
```

Проверяется настоящий локальный WASM Worker, исходные File API данные остаются в браузере. Общая автоматическая последовательность находится в `.github/workflows/platform.yml`; [текущая архитектура и сборка](../../docs/platform.md).

Браузерный тест проверяет режимы сравнения R05 и отвергает изменение наблюдения или его хеша. Публичный пакет содержит только разрешённые синтетические материалы.
