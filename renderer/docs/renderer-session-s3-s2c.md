# S3-S2C — вывод целого объекта через WebGPU

Кандидат [FGMV-SESSION-004](../../requirements/renderer/FGMV-SESSION-004.rg.yaml) продолжает сквозную проверку S3-S2B. Сессия использует тот же путь загрузки сцены для Canvas2D и WebGPU. Он копирует входные байты, сверяет SHA-256 и ссылки, разбирает один OBJ. Каноническая модель и игровые данные принадлежат принятым регенератору и ядру.

## Контракт вывода

- Сессия запрашивает адаптер и устройство WebGPU и создаёт два графических конвейера до привязки холста. Если WebGPU недоступен, вызов с политикой `reject` возвращает `E_SESSION_BACKEND_UNSUPPORTED`. Вызов с политикой `allow-diagnostic` может открыть Canvas2D.
- Бэкенды используют одну орбитальную проекцию и одну систему координат клеток. WebGPU рисует треугольники производного OBJ с буфером глубины и выделяет выбранную клетку в собственной текстуре. Сессия передаёт её готовые RGBA-пиксели на холст. Вывод через чтение текстуры оставляет растеризацию на GPU и не требует текстуры браузерного GPU-холста.
- Загрузка и смена вида по-прежнему очищают старый кадр. Пока GPU готовит кадр, сессия отслеживает отмену и замену запроса. Готовые пиксели отображаются после проверки актуальности. Потеря устройства очищает холст и возвращает `device-lost` для актуального кадра. Восстановление устройства остаётся отдельным этапом.
- Срез касается библиотеки и тестового Chromium-исполнителя. Подключение к постоянному интерфейсу Studio и игровому клиенту относится к S3-S3.

## Проверка

Тест `tests/renderer-session-wasm.browser.mjs` берёт реальный Worker из проверенного пакета Pages. Одни и те же байты FGM/OBJ для 2×1 и 2×2 проходят через диагностическую и WebGPU сессии. Chromium должен увидеть пиксели геометрии и выделенной клетки и затем подтвердить очистку при ошибке SHA-256. В CI WebGPU выполняется через SwiftShader, который позволяет проверить графические команды без выделенной видеокарты. Этот тест не измеряет производительность на физическом GPU.

```sh
npx tsc -p runtime/tsconfig.json
node --test tests/renderer-session.test.mjs tests/renderer-session.browser.mjs
node tests/renderer-session-wasm.browser.mjs build/pages-studio
```
