# FGM Core — математическое ядро

Единственный evaluator FGM-0 на C++20: математическая семантика, геометрия, пространство, материалы и каноническая сериализация. Камера и художественный профиль не меняют идентичность или C05 модели.

## Сборка и разработка

Обычная сборка выполняется из корня [FGM Platform](../README.md). [Архитектура, native/WASM и проверки](../docs/platform.md), [нормативные требования](../requirements/core/), [единая иерархия](../docs/requirements-hierarchy.md). Отдельный репозиторий, lockfile или workflow модуля не требуются.
